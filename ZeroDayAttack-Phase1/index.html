Knowledge Base

Frequently asked questions

Understand how the neural detection model operates under real production constraints.

How does an autoencoder detect zero-day attacks? +
An autoencoder is trained to reconstruct benign network traffic. When normal traffic enters, the reconstruction error (Mean Squared Error) is very low. However, when a zero-day exploit or anomalous payload enters, the network fails to reconstruct the unfamiliar pattern, causing a sudden spike in reconstruction error that triggers an alert.
Why not use traditional signature-based detection? +
Signature-based detection (like standard AV or IDS) requires that an attack has been previously identified, cataloged, and converted into a rule. Zero-day attacks are novel by definition—no existing signature exists. Unsupervised anomaly detection identifies attacks based on behavior rather than matching static signatures.
What does the sensitivity threshold control? +
The threshold defines the Mean Squared Error (MSE) boundary between normal traffic and an anomaly. A lower threshold (e.g., 0.30) increases sensitivity, capturing subtle deviations with a potential slight increase in false alerts. A higher threshold (e.g., 0.80) only flags extreme anomalies.
Which datasets were used to calibrate Phase 1? +
Phase 1 leverages the NSL-KDD benchmark dataset, using 41 dimensional features including protocol types, service endpoints, transmission byte counts, error rates, and connection flags normalized with min-max scaling.
